    Why it works: the pattern survives

    A Caesar shift only slides the bars sideways. The shape of the letter distribution stays the same, so the tallest bar gives the key away.

    How the shift works

    Encryption is a function you can run backwards. Understand these four ideas and you understand the whole project.

    Input, process, output

    Plaintextreadable data
    Algorithm + keythe rules and the secret
    Ciphertextunreadable without the key

    Every cryptographic system, from Caesar to AES, follows this shape. Only the middle box changes.

    Text becomes numbers first

    Computers store letters as numbers (ASCII). A is 65, Z is 90, a is 97, z is 122. We do not shift letters; we shift integers.

    Try one letter through the pipeline:

      The two formulas

      E(x) = (x + n) mod 26

      D(x) = (x − n) mod 26

      x is the letter's position (A = 0), n is the key. The mod 26 wraps Y + 3 = 27 back around to B.

      Watch out: in JavaScript, -3 % 26 is -3, not 23. This project uses a true modulo so decryption never breaks.

      The same idea in Python

      def caesar(text, shift, decrypt=False):
    if decrypt:
        shift = -shift
    result = []
    for ch in text:
        if ch.isascii() and ch.isalpha():
            base = ord("A") if ch.isupper() else ord("a")
            result.append(chr((ord(ch) - base + shift) % 26 + base))
        else:
            result.append(ch)      # keep spaces and punctuation
    return "".join(result)

secret = caesar("Hello, World!", 3)          # Khoor, Zruog!
print(caesar(secret, 3, decrypt=True))       # Hello, World!

      Why Caesar is a lockbox, not a vault

      • Tiny key space. Only 25 keys. A laptop tries them all in well under a millisecond.
      • Patterns survive. The letter E is still the most common letter, just relabelled. Frequency analysis spots it.

      Vigenère hides the pattern by changing the shift per letter, but it still falls to statistical attacks. Try both in the Workbench.

      Where real encryption goes next

      • Confusion and diffusion. Modern ciphers scramble the relationship between key and output, and spread each input bit across many output bits.
      • Huge keys. AES uses 128-bit or larger keys: about 3.4 × 1038 possibilities instead of 25.
      • XOR and substitution rounds repeated many times.

      Never use Caesar, Vigenère or Atbash to protect anything real. They are for learning.
